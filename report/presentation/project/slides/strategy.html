Empirical strategy

Frozen protocol before the first regression

Y(i,t) = country FE + quarter FE + β₁·Pre + β₂·Post + γ′·(last year's fundamentals) + ε

  • Pre = election quarter and quarter before
  • Post = the two following quarters
  • Outcomes: gross inflows and outflows, % GDP
  • Identifying sample: scheduled elections
  • Errors clustered by country, plus Driscoll–Kraay, two-way, wild bootstrap
  • Holm adjustment over the primary family
  • 34 pre-specified robustness tests
  • Git tag timestamps the protocol
Moderators are fixed at 2014 levels so they are predetermined; their main effects are absorbed by country fixed effects. Controls are lagged a year to avoid conditioning on mediators like the exchange rate.
